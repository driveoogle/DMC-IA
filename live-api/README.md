# live-api
Fonction Vercel qui valide le mot de passe et renvoie l'ID du live YouTube.
Deploy: nouveau projet Vercel, Root Directory = `live-api`.
Variables d'environnement: `LIVE_VIDEO_ID`, `LIVE_ACCESS` (ex: `marie:mdp1,paul:mdp2`).
Puis mettre l'URL du projet dans `LIVE_API` en haut du script de `live-x7k2q9.html`.
